# 粗粒度模型的层次

`models/coarse/` 是唯一的生成模型实现。持久状态保存通信元信息与资源占用；
`EventQueue` 按事件时间和插入顺序推进。模型时间只由事件和显式预算改变，
维护事件堆和遍历元信息所需的宿主执行步不直接计入 NoC 时间。

源端先完成整包读服务，链路逐 flit 流水转发，目的端整包接收后安排写服务。
组播公共树干只发送一次，分支各自争用方向链路；目的接收仲裁独立于链路与写端口。
完成事件记录传输身份与字节量，替代详细模型中的真实字节写入。

`src/wse_model/programs/coarse.py` 提供新的无地址接口，`coarse_allgather.py` 构造
32 参与者的两阶段 AllGather。对照适配器从独立旧分支工作区
读取旧路由和程序编码模块；本分支不携带旧模型实现。

`verification/coarse_cases.py` 与 `tests/test_coarse.py` 持有独立预期和资源守恒检查，
不参与模型运行。两后端从同一个 final.ac 生成。Verilator 是二值仿真，对照范围
采用已知输入；实际数据内容与详细地址正确性由旧分支的独立对照承担。
