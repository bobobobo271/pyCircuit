# 无地址通信接口

接口定义在 `src/wse_model/programs/coarse.py`。`Route` 给出源、转发树边和接收目标；
`Transfer` 给出唯一传输 ID、源、路由编号、有效字节数、逻辑块标识、释放时间、依赖组
和完成组。节点可以同时接收并向下游转发，源本地副本只占端点服务、不占链路。

`WaitGroup` 等待组的目标接收服务完成。`Barrier` 等所有活动和排队传输排空后，增加
配置准备预算，并重新建立 Calendar 时间原点。`RetireGroup` 释放该组的接收容量。
新程序应显式表达依赖；旧字节地址之间的别名关系由比较适配器检查，不能直接丢弃。

`Workload.write()` 输出的装载记录是模拟器元信息，不是被模拟设备的寄存器映射。
模型的接收容量、队列和事件堆都有边界：队列占满时等待，容量越界显式失败。

v1 的通信组采用封闭成员集合：装载时确定该组全部目标完成数，组编号在整个工作负载
中唯一。WaitGroup 等待这个完整集合；它不会仅等待“此前已经发出的部分”。调用者须
先发布所需生产者，再等待或消费该组。RetireGroup 当前采用全局排空后释放该组容量。

规模边界为 40 节点、256 个路由编号、255 个组编号、1024 条命令（包括结束命令），
每包至多 65,535 个 flit。读写端点使用相同拍宽与后续拍速率，首读和首写延迟可分别
设置。逻辑块标识随传输保存；运行时依赖按组完成执行，不维护逐块数值账本。
